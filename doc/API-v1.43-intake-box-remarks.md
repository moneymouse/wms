# API v1.43：拍照装箱单逐箱备注与批量修改

日期：2026-10-09。

## 每箱备注

纸单识别候选、`PUT /api/intakes/<uid>/draft` 和详情的 `draft.boxes[]` 支持可选的 `remark`：

```json
{
  "box_number": 1,
  "item_name": "衣服",
  "count": 12,
  "weight": 8.5,
  "worker_ids": [2],
  "remark": "易碎，请轻放"
}
```

备注须为去掉首尾空白后不超过 512 字的文字；空字符串、纯空白或 `null` 表示清空。草稿中的空备注规范化为 `""`。旧客户端或历史草稿没有 `remark` 时仍兼容，读取和保存不会给旧箱子补上该字段。任何箱子备注类型无效或超过限制时，整个草稿保存失败（400），草稿内容与版本保持原样。

`POST /api/intakes/<uid>/confirm` 重新校验并把每箱备注写入对应正式箱子的 `cargos.remark`；空备注写为 `null`。正式箱子详情继续使用现有 `remark` 字段。本次使用既有数据库字段，不新增迁移。

识别只抄录明确属于对应箱子的备注，不从整单或上一箱复制备注；无法辨认或未填写时留空。识别候选超过 512 字时截取并加入 `warnings`，提醒对照原图核对。

## 检查页修改

拍照上传后的编辑页每箱增加备注输入列。批量修改备注沿用选择箱子的操作，一次设置所选箱子的 `remark`；提交空备注可清空所选箱子的原备注。最终通过原草稿保存接口持久化，沿用上传者本人核对及版本冲突保护。
