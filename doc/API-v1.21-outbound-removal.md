# 包裹移除与撤销出库

## 移除规则

包裹当前已出库或进入后续物流状态时，订单解绑、货物删除/归档、箱子删除/归档、装箱单删除以及会解绑包裹的订单硬删除返回 `409`，提示先撤销出库。后端在业务事务中锁定并重新读取货物状态；混合批量移除若包含一个已出库包裹，整批保持不变。

规则判断当前 `status` 和出库 `date`，不因存在历史出库记录而永久禁止移除。已有整单归档流程保留。

货物列表新增 `removal_allowed: boolean` 和 `removal_blocked_reason: string | null`。前端以这两个字段展示移除状态，避免外部物流平台的历史跟踪状态覆盖当前撤销结果。

## POST /api/cargo/{uid}/undo-outbound

权限：`admin`、`store_manager`。无请求体。

在同一事务中锁定订单和包裹，撤销当前出库：`status=0`、`date=null`、`waybill_id=""`。保留原单号、订单关联、原出库事实、收款与奖金记录；当前有效箱成本记录转为归档，不删除历史。订单历史记录操作人和 `cargo_shipment_undone`（普通包裹）或 `box_shipment_undone`（箱子）动作。历史写入失败时撤销操作一并回滚。

成功：`200`，`data` 为 `{ "uid": "...", "status": 0, "date": null, "waybill_id": "" }`。

错误：`403` 无撤销权限；`404` 包裹不存在；`400` 当前未出库或已归档；`409` 锁定时发现归属或状态冲突。

撤销成功后可重新出库或从订单移除；箱子原单号的历史身份保护仍生效。原 `POST /api/box/{uid}/undo-ship` 继续保留。
