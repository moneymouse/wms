# WMS Backend API 接口文档 - v0.1 更新

**Base URL:** `http://localhost:5001`

**版本:** 0.1 (2026-03-27)

---

## 更新内容概述

本版本更新内容：

### 1. 订单负责人（业务员）管理功能

- 订单与用户（负责人）之间为**多对一**关系（一个订单只有一个负责人，一个业务员可以负责多个订单）
- 创建订单时，**自动将创建者设为负责人**
- 提供负责人的查询和修改接口
- **权限控制**：只有 `admin` 或当前订单的负责人才能修改负责人

### 2. 用户角色管理功能

- 支持管理员为用户**添加和删除角色**
- 可用角色：`admin`, `store_manager`, `salesperson`, `clerk`, `finance`

---

## 通用说明

### 认证方式

除特殊标注外，所有接口均需要在请求头中携带 JWT Token：

```
x-token: <JWT_TOKEN>
```

### 响应格式

所有接口返回 JSON 格式，基本结构：

```json
{
  "code": 200,
  "msg": "success",
  "data": {}
}
```

### 状态码说明

| code | 说明                       |
| ---- | -------------------------- |
| 200  | 成功                       |
| 400  | 请求参数错误               |
| 401  | 未授权（Token 无效或过期） |
| 403  | 权限不足                   |
| 404  | 资源不存在                 |
| 500  | 服务器内部错误             |

### 1. 创建订单（更新）

创建新订单，**自动将当前用户设为订单负责人**。

- **URL:** `POST /api/create`
- **认证:** 需要

**请求参数:**

```json
{
  "order_id": "ORD20260326001",
  "customer_name": "客户A",
  "receiver": "收件人姓名",
  "receiver_phone": "13800138000",
  "address": "收件地址",
  "zip_code": "100000",
  "country": "中国",
  "tag_all": "标签",
  "cargo_count": 3
}
```

**响应示例:**

```json
{
  "code": 200,
  "msg": "success"
}
```

**行为变更:**

- 创建订单时，自动将发起请求的用户设置为订单的唯一负责人

---

### 2. 获取订单负责人

获取指定订单的负责人信息。

- **URL:** `GET /api/orders/<uid>/salesman`
- **认证:** 需要

**路径参数:**

| 参数 | 类型   | 说明         |
| ---- | ------ | ------------ |
| uid  | string | 订单唯一标识 |

**响应示例:**

```json
{
  "code": 200,
  "data": {
    "id": 1,
    "name": "张三",
    "phone": "13800138000"
  }
}
```

**如果订单没有负责人:**

```json
{
  "code": 200,
  "data": null
}
```

---

### 3. 更新订单负责人

修改订单的负责人。

- **URL:** `PUT /api/orders/<uid>/salesman`
- **认证:** 需要
- **权限:** `admin` 或当前订单的负责人

**路径参数:**

| 参数 | 类型   | 说明         |
| ---- | ------ | ------------ |
| uid  | string | 订单唯一标识 |

**请求参数:**

```json
{
  "user_id": 2
}
```

| 参数    | 类型     | 必填 | 说明                            |
| ------- | -------- | ---- | ------------------------------- |
| user_id | int/null | 是   | 用户 ID，设为 null 可移除负责人 |

**响应示例（设置负责人）:**

```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "id": 2,
    "name": "李四",
    "phone": "13900139000"
  }
}
```

**响应示例（移除负责人）:**

```json
{
  "code": 200,
  "msg": "success",
  "data": null
}
```

**错误响应:**

| code | msg                                                           |
| ---- | ------------------------------------------------------------- |
| 401  | Unauthorized                                                  |
| 403  | Permission denied. Only admin or current salesman can modify. |
| 404  | User not found / Order not found                              |

## 权限说明

### 负责人修改权限

| 角色           | 权限说明                     |
| -------------- | ---------------------------- |
| `admin`        | 可以修改任意订单的负责人     |
| 当前订单负责人 | 可以修改自己作为负责人的订单 |
| 其他用户       | 无权修改负责人               |

### 1. 修改用户角色

为用户添加或删除角色。

- **URL:** `PUT /api/users/<user_id>/role`
- **认证:** 需要
- **权限:** `admin`

**路径参数:**

| 参数    | 类型 | 说明    |
| ------- | ---- | ------- |
| user_id | int  | 用户 ID |

**请求参数:**

```json
{
  "role": "salesperson"
}
```

| 参数 | 类型        | 必填 | 说明                                     |
| ---- | ----------- | ---- | ---------------------------------------- |
| role | string/null | 是   | 角色名称，设为 `null` 或 `""` 可删除角色 |

**响应示例（设置角色）:**

```json
{
  "code": 200,
  "msg": "角色已更新",
  "data": {
    "id": 2,
    "phone": "13900139000",
    "name": "李四",
    "role": "salesperson",
    "status": "approved"
  }
}
```

**响应示例（删除角色）:**

```json
{
  "code": 200,
  "msg": "角色已删除",
  "data": {
    "id": 2,
    "phone": "13900139000",
    "name": "李四",
    "role": null,
    "status": "approved"
  }
}
```

**错误响应:**

| code | msg                                                                   |
| ---- | --------------------------------------------------------------------- |
| 400  | 无效角色，可选角色: admin, store_manager, salesperson, clerk, finance |
| 404  | 用户不存在                                                            |

### 2. 获取全部用户

获取系统中所有用户列表（不包含被拒绝的用户）。

- **URL:** `GET /api/users`
- **认证:** 需要
- **权限:** `admin`

**说明:**

- 返回的用户列表**不包含**状态为 `rejected` 的用户

**响应示例:**

```json
{
  "code": 200,
  "data": [
    {
      "id": 1,
      "phone": "admin",
      "name": "Administrator",
      "role": "admin",
      "status": "approved"
    },
    {
      "id": 2,
      "phone": "13900139000",
      "name": "李四",
      "role": "salesperson",
      "status": "approved"
    }
  ]
}
