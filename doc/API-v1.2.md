# WMS Backend API 接口文档 - v1.2 更新

**版本:** 1.2 (2026-08-30)

## 应收账款日期范围

- `GET /api/finance/accounts-receivable` 新增 `date_from`、`date_to` 参数，格式均为 `YYYY-MM-DD`，起止日期包含在统计范围内。
- 区间总应收按报价 `effective_date` 落在范围内的订单计算。
- 已收、未收和待审核金额按 `date_to` 当日 23:59:59 的历史状态重建。
- 原 `as_of` 参数暂作为 `date_to` 的兼容参数保留。

## 应收计费重量

- 应收账款按整公斤计费，原始重量通过 `weight_snapshot` 保留，计费重量通过 `billing_weight` 返回。
- `billing_weight` 按每个包裹分别向上取整后求和，例如两个 `21.2kg` 包裹的计费重量为 `22 + 22 = 44kg`，不是将订单总重 `42.4kg` 取整为 `43kg`。
- 应收金额公式调整为 `round(billing_weight × unit_price + surcharge, 2)`。
- 有效报价的应收始终按订单当前有效包裹实时计算，报价快照仅作审计记录。
- 创建首张收据时，当时的原始重量、计费重量和应收会写入最终报价及收据快照。
- 任意状态的收据一旦生成，订单包裹重量、包裹增删/分配和新报价永久锁定；被驳回的收据也不解锁。

## 收款管理未结清总览

- `GET /api/receivables/orders` 的 `customer_id` 改为可选。
- 无论是否传入 `customer_id`，都只返回 `实时应收 > 已审核 + 待审核` 的当前可收款订单。
- 收款登记页面的客户字段为可选筛选项；未选择时可直接选择订单，但同一收款单只能包含同一客户，提交时从所选订单自动确定客户。
- 未结清订单和收款单记录均使用 `p`、`s` 服务端分页；收款单列表只返回摘要，展开时再请求单条明细。

## 装箱单分配分页

- `GET /api/boxes/unassigned` 新增 `p`、`s` 服务端分页参数，默认每页 10 个装箱单。
- `q` 唛头搜索在服务端执行，响应返回 `items`、`total`、`total_boxes`、`page` 和 `page_size`。

## 订单列表搜索

- `GET /api/orders` 的 `q` 参数支持按订单负责人（业务员）姓名模糊查询。
