# 财务系统使用说明

本说明面向业务员、财务和管理员，说明客户订单从报价、收付款登记到核销结清的操作，以及旧收款记录导致订单不可选时的处理方法。页面左侧的入口名称是「财务」，本文将该页面称为财务中心。

业务员负责报价、登记实际收付款并提交；财务负责核对资金、确认收付款、分配核销和检查余额。业务员提交以后，应由财务接手办理。

## 业务员登记收付款后下一步做什么

先在左侧「收付款 → 收付款记录」找到登记的收付款单，确认其状态，再按下面的表处理。

| 当前状态 | 下一步操作 | 负责人 |
| --- | --- | --- |
| 草稿 | 打开详情，核对信息后点击「提交」 | 登记人 |
| 待财务确认 | 财务打开同一笔记录，核对资金后点击「确认收付款」，或「退回修改」 | 财务或管理员，须由登记人以外的人员审核 |
| 已生效，仍有可核销余额 | 在财务中心的收付款详情点击「核销订单」，选订单并填写本次分配金额 | 财务或管理员 |
| 已生效，订单核销完成 | 检查订单待补收、待退和资金未分配余额，判断是否还需后续收款或退款 | 财务检查，业务员跟进客户 |

「已生效」表示这笔资金已经财务确认。订单是否结清，需要查看实际核销结果。登记时选择的「参考订单」只作备注，不会自动将款项抵扣到订单。

## 客户订单日常操作流程

### 业务员报价并登记实际资金

1. 在订单中完成报价；需要审批的报价由有相应权限的人员审核，使订单具有有效报价。
2. 客户实际付款后，在订单详情点击「登记收付款」，或进入左侧「收付款 → 收付款记录」点击「登记收款」。
3. 填写客户、收付款账户、实际金额、实际资金日期，以及流水号或支付参考号。可以选择参考订单并填写备注。
4. 点击「提交」。若点击的是「保存」，记录仍是草稿，需要再打开详情点击「提交」。
5. 确认记录显示「待财务确认」，将资金凭据和实际用途交给财务核对。

按实际资金金额登记。例如订单应收 1,000 元，客户只转来 600 元，本次收款就登记 600 元。预收款也可以先登记，参考订单可以不选。

### 财务核对并确认收付款

1. 进入左侧「财务 → 收付款」，筛选「待财务确认」。也可以在「总览」点击「待确认收付款」的「查看」。
2. 打开业务员登记的同一笔收付款单，核对客户、账户、金额、资金日期、支付凭据和是否重复登记。
3. 信息正确时点击「确认收付款」，使记录变为「已生效」。
4. 信息有误时点击「退回修改」，填写原因。登记人修改原草稿后重新提交，沿用原记录。

登记人不能审核本人提交的收付款。财务办理业务员提交的款项时，应继续使用原记录。

### 财务将收付款核销到订单

1. 在「财务 → 收付款」打开已生效的客户收付款，确认「可核销余额」大于零。
2. 点击「核销订单」。
3. 重新选择实际抵扣的订单。登记时的参考订单不会自动带入核销选择。
4. 客户收款分配到订单的待收金额；付给客户的退款分配到订单的可退金额。
5. 填写各订单的本次核销金额。每笔金额须大于零，不超过订单可核销余额；合计不超过资金可核销余额。
6. 核销日期使用今天，核对金额后点击「确认订单核销」。
7. 在收付款详情检查核销记录，并在「财务 → 订单应收」检查订单的「待补收」和「待退」。

系统会先按当前有效报价和货重确认或调整订单账单，再生成核销记录。日常客户订单结算可以直接走「核销订单」；该操作会完成对应的账单确认，无需再手工开一张相同的应收账单。

## 订单不可选并提示存在待审核收款

提示「存在待审核收款，请先完成原收款审核」指订单关联的旧版收款单。新收付款页面中的「待财务确认」和旧版收款单中的「待审核」是不同记录；确认新收付款不会自动审核旧记录。

处理这一步的人是财务或管理员。

1. 进入「财务 → 历史收款清理」。
2. 将状态筛选为「待审核」。
3. 展开收款单明细，找到包含该订单的旧收款单，核对收款日期、金额、支付凭据以及对应的新收付款记录。
4. 点击该旧收款单的「审核」，根据实际资金事实选择下面的处理方式。

| 核对结果 | 财务处理方式 | 随后操作 |
| --- | --- | --- |
| 旧待审记录与新登记收付款代表同一笔钱，并决定以新记录办理 | 对重复的旧待审记录点击「驳回」，填写重复登记的原因，并注明新收付款单号 | 回到新收付款详情，刷新订单列表后继续核销 |
| 旧待审记录是错误登记或没有对应实际收款 | 点击「驳回」，填写核对结果 | 刷新订单列表，检查是否还有其他待处理事项 |
| 旧记录是应保留的真实历史收款 | 核对正确后点击「审核通过」；如已存在同一笔资金的新记录，先由财务核准并处理重复记录 | 按下面的旧账接入流程处理历史余额，然后核销实际新增资金 |

驳回需要填写审核意见。旧收款的创建人也不能审核自己的收款单。

若旧收款审核通过后，又提示「历史已审收款须先通过旧账净余额接入」，由财务进入「财务 → 会计与月结 → 旧订单接入」，选择订单、核对有效报价及旧已审收款，确认需要接入的净余额。符合当前建账条件时，填写依据并点击「确认接入期初」。

旧账接入只处理核对后的历史余额。比如旧订单应收 1,000 元、历史已收 600 元，接入的是剩余应收 400 元；之后只把新增收款核销到这 400 元。历史 600 元应按旧账口径保留，避免又作为一笔新资金抵扣。

若期初已经确认、建账日期与今天不一致，或订单已接入但来源后来变化，该页面会提示具体限制。由财务核准期初或接入差异，按照页面要求处理调整凭据，不重复接入。

## 怎样确认一个订单处理完成

假设一个新订单应收 1,000 元，客户实际支付 600 元，没有历史收款或其他调整。

| 办理阶段 | 收付款状态 | 资金未分配余额 | 订单待补收 |
| --- | --- | --- | --- |
| 业务员保存 | 草稿 | 尚不可核销 | 1,000 元 |
| 业务员提交 | 待财务确认 | 尚不可核销 | 1,000 元 |
| 财务确认资金 | 已生效 | 600 元 | 1,000 元 |
| 财务核销 600 元到订单 | 已生效 | 0 元 | 400 元 |
| 后续收款 400 元并完成确认及核销 | 两笔款均已生效 | 两笔均为 0 元 | 0 元 |

该订单待补收为零、待退为零，表示按当前应收和有效核销已无待收待退款项。报价或货重后来变化时，仍需重新核对应收。

如果客户实际支付 1,200 元，只核销其中 1,000 元，订单可结清，剩余 200 元仍是客户未分配资金，可用于后续核销或经财务核准办理实际退款。

## 订单账单收付款分别管什么

| 对象 | 含义 | 与其他对象的关系 |
| --- | --- | --- |
| 订单 | 运输业务、货物、重量和报价 | 财务确认当前应收时，生成对应账单；报价变化可产生追加账单或调减贷项 |
| 账单 | 应向客户收取、应向供应商支付或需要调减的账款 | 保存已确认金额，通过核销记录计算未结金额 |
| 收付款 | 实际资金收付、日期、账户和凭据 | 经财务确认后，可分配给一个或多个订单或账单 |
| 核销记录 | 某笔资金或贷项抵扣了哪张账单、多少金额 | 建立正式结算关系，支持部分核销及撤销 |

一笔款可以分给多个目标，一张账单也可以由多笔款分次结清。已确认的资金金额不会随订单报价或货重变化。

| 操作 | 何时使用 | 负责人 |
| --- | --- | --- |
| 核销订单 | 客户订单收款或订单退款，按当前有效报价核对余额 | 财务或管理员 |
| 核销账单 | 独立客户账单、供应商账款及其他已核准账单 | 财务或管理员 |
| 确认当前报价 | 尚未核销资金，但需要先确认订单应收或报价变化 | 财务或管理员，在「订单应收」办理 |
| 撤销核销 | 资金分配错了，需要释放余额并重新分配 | 财务或管理员，在核销记录中办理 |
| 冲销收付款 | 已生效的资金登记需要更正 | 财务或管理员，先处理该资金的有效核销及其他相关限制 |

订单管理生成的账单需通过「核销订单」办理。普通账单核销页面会将这些账单置为不可选，并显示相应提示。

## 常见后续情况

| 情况 | 操作方式 |
| --- | --- |
| 客户只付一部分 | 登记实际金额，财务确认后部分核销，业务员跟进剩余待补收 |
| 客户合并支付多个订单 | 登记一笔实际收款，财务在「核销订单」中按用途分配给多个同客户订单 |
| 款项是预收款，暂时没有可核销订单 | 先登记并确认资金，余额保留，等有效应收具备后由财务核销 |
| 报价或货重变了 | 财务在「订单应收」查看变化，点击「确认当前报价」，填写说明并「确认入账」，或在下一次订单核销时一并确认 |
| 订单调减后产生待退 | 财务先确认调减，使应退有账款依据；实际退款按客户付款登记、确认，再核销到订单的可退金额 |
| 选错订单 | 财务在收付款详情的核销记录中「撤销核销」，再重新分配；撤销核销不会自动退钱 |
| 订单列表提示报价或余额已变化 | 刷新列表，重新核对本次分配金额后办理 |
| 提示创建人不能审核本人记录 | 交由另一位有财务或管理员权限的人员核对 |
| 提示日期所在期间已关账或没有开放期间 | 财务在「会计与月结 → 期间与关账」核对相关期间 |

## 财务中心各页面的用途

| 页面 | 日常用途 |
| --- | --- |
| 总览 | 查看待确认收付款、未结账款和其他财务待办 |
| 收付款 | 财务确认、退回、核销、打印及更正实际资金记录 |
| 订单应收 | 查看当前应收、有效核销、待补收、待退和报价变动；确认报价形成账单 |
| 账单 | 查询客户及供应商账单，办理独立账单和贷项 |
| 往来对账 | 核对客户或供应商的账款及资金往来 |
| 历史收款清理 | 处理旧版收款单的剩余审核，查询和核对历史记录 |
| 会计与月结 | 账簿设置、期间、凭证、履约收入、旧订单接入、银行对账和报表 |
| 基础资料 | 维护供应商、资金账户等财务资料 |

首次使用时，由财务或管理员先完成账簿设置、所需资金账户和开放会计期间。期初及旧账由财务核准后办理；业务员可以继续负责客户报价和实际资金登记。
