# API v1.4：收款登记订单筛选

`GET /api/receivables/orders` 新增可选查询参数：

| 参数 | 说明 |
| --- | --- |
| `date_from` | 订单创建日期下限，`YYYY-MM-DD`，包含当天 00:00:00 起的订单 |
| `date_to` | 订单创建日期上限，`YYYY-MM-DD`，包含当天 23:59:59 的订单 |
| `owner_id` | 当前有效报价的负责人 ID，仅管理员生效 |

日期可以单独传入一端，不传则不限日期。日期格式错误、无效日期或起始日期晚于结束日期返回 `400`。

普通业务员传入 `owner_id` 时忽略此参数，始终只能查询自己的有效报价对应的可收款订单。管理员不传 `owner_id` 时可查询所有负责人。

以上参数可与原有 `customer_id`、`q` 组合使用。所有过滤均在统计 `total` 和执行 `p`、`s` 分页之前生效。默认分页、排序和可收余额规则保持原有行为。

响应 `data` 中每条订单新增 `create_date`，来自订单创建时间，格式为 `YYYY-MM-DD HH:mm:ss`；历史记录缺失时为 `null`。

`POST /api/receipts` 请求结构保持不变。收款登记页面改为选择订单后在弹窗中填写收款日期、收款方式及备注并提交；此调整不涉及数据库迁移。
