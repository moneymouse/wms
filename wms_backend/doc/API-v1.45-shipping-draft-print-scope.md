# API v1.45：出货确认单草稿打印范围

「保存并打印 PDF」沿用草稿表格已有选择：勾选装箱单会选中该组箱子，也可以展开后单独勾选箱子。未勾选时打印当前草稿全部箱子，有勾选时只打印这些箱子。

保存仍提交完整草稿的全部 `entries`。打印范围只在 PDF 请求中使用，不删除未选条目、不标记已打印、不写打印历史、不改变箱子、装箱单或出货状态。

`POST /api/shipping-confirmation-drafts/<uid>/pdf` 保留原认证、草稿归属权限及版本校验，新增可选范围：

```json
{"expected_version": 4, "cargo_uids": ["box-a", "box-c"]}
```

- 不提供 `cargo_uids`：打印草稿全部内容，兼容原请求。
- 提供范围：必须是最多 500 项的非空字符串列表，每个编号须属于当前草稿；按照完整草稿中的顺序输出，并保留草稿保存的代理及备注。重复编号只输出一次。
- 显式空列表、`null`、错误类型、空编号、过长编号或包含草稿外编号返回 400，不能回退为打印全部或忽略错误项目。
- 草稿版本失效返回 409；所选箱子被删除或归档、关联装箱单被删除或归档返回 404，不生成 PDF。未选范围内的失效箱子不阻止已保存草稿打印有效选中项。
- 沿用现有权限：业务员、文员只可访问自己的草稿，管理员及店长保持原有全局草稿权限；未认证 401、无权限 403。

前端在保存前保留选择快照，保存成功后使用返回的草稿 ID 和版本打印。若保存后的草稿不再包含所选项目，或项目已失效，显示错误并保留已保存完整草稿，不发出打印全部的请求。保存失败则不请求 PDF；PDF 失败不撤销已完成的完整草稿保存。

本变更无需数据库迁移，不执行实际出货、生产重启或部署。
