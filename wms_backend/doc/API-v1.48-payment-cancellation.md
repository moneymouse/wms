# 收付款财务确认前撤销

`POST /api/finance/v2/payments/{id}/cancel` 现在支持 `draft`（草稿）和 `pending`（待财务确认）。

请求保持不变：`version` 为当前版本，`reason` 为必填撤销原因，可传 `idempotency_key` 防止重复提交。

业务员只能撤销本人登记的非期初客户收付款；财务、管理员沿用现有收付款管理权限。已生效、已冲销、已撤销的记录不可撤销。撤销和财务确认共用事务锁与版本校验，过期请求返回 409。

撤销后状态为 `cancelled`，原编号、金额和提交信息保留，记录 `cancelled_at`、`cancellation_reason`。现有修改历史中保存 `cancel` 事件、操作人、时间、原因和前后快照，不生成会计凭证或核销。原收据无效，需要更正时重新登记。

收付款详情在财务确认前提供「撤销收付款」按钮；已撤销记录显示原因，仍可查看修改历史及打印标记为无效的凭证。
