# API v1.47：出货草稿筛选与报价版本查看

日期：2026-10-23。本次复用既有接口、查询参数和报价字段，无数据库结构变更。

## 出货确认单草稿的装箱单查询

草稿页面初次加载、分页及搜索均使用：

`GET /api/packing-lists?box_status=outbound&exclude_box_status=true&p=1&s=20&q=搜索词`

沿用服务端 `box_status` 聚合筛选：非草稿且全部未归档箱子均已出货的装箱单不进入候选列表。过滤在 SQL `HAVING` 中执行，早于总数统计和分页，因此 `total` 与返回结果保持一致。部分出货、仍有待分配或待出库箱子、撤销出库后的装箱单仍可搜索；已归档箱子不参与状态判断。

普通装箱单列表继续按其自身筛选参数查询。已有出货确认单草稿的读取及打印接口不变。

## 报价版本查看与报价权限

- `GET /api/orders/<uid>/quotes`：沿用 `admin`、`store_manager`、`salesperson`、`finance` 查看角色，不要求当前用户为订单业务员。
- 订单详情为上述角色提供报价版本入口。非当前订单业务员打开只读版本列表，不展示报价输入表单或提交按钮；当前订单业务员保留原报价流程。
- `POST /api/orders/<uid>/quotes`：继续要求业务员角色且用户为当前订单业务员，其他用户提交返回 `403`，不创建或改写报价版本。
- `GET /api/orders/<uid>/quote-pdf`：沿用现有查看角色，允许只读用户打印当前采纳报价。

报价版本列表展示每条记录自身的 `quote_remark`（报价说明），保留换行和长文本换行；历史版本没有说明时显示 `-`。说明继续使用已有响应字段，不从当前报价表单推断历史内容。
