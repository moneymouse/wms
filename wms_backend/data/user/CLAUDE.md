# User 用户模块

## 功能概述
用户模块负责系统用户的管理，包括用户认证、角色权限和用户状态管理。

## 数据模型

### UserTable
用户表，存储系统用户信息：
- `id`: 用户唯一标识
- `phone`: 手机号（唯一，用于登录）
- `name`: 用户姓名
- `password`: 加密后的密码
- `role`: 用户角色
- `status`: 用户状态（pending/approved/rejected）
- `remark`: 备注信息
- `create_date`: 创建时间
- `update_date`: 更新时间

## 用户角色

系统支持以下五种角色：
- **admin**: 系统管理员，拥有最高权限
- **store_manager**: 仓库管理员，管理仓库操作
- **salesperson**: 销售人员，处理订单和客户
- **clerk**: 文员，执行日常操作
- **finance**: 财务人员，处理财务相关操作

## 用户状态流转

1. **pending**: 用户注册后的初始状态，等待审批
2. **approved**: 管理员审批通过，用户可以正常登录使用
3. **rejected**: 管理员审批拒绝，用户无法登录

## 安全特性
- 密码加密存储（使用bcrypt等安全算法）
- 手机号唯一性验证
- 用户审批机制防止恶意注册
- 角色权限控制访问范围
